# Privacy Policy

This application is a personal, single-user OAuth client. It connects the Rail terminal
mail client, running on the owner's own computer, to the owner's own Gmail account.

**Data accessed.** The application requests access to the owner's own Gmail mailbox so the
mail client can read, search, send and organize that mail.

**Data storage.** Mail and access tokens are stored only on the owner's own computer.
No data is sent to, stored on, or processed by any server operated by the application's
owner or any third party, other than Google's own Gmail service.

**Data sharing.** No data is sold, shared, or disclosed to anyone.

**Other users.** The application is not available to anyone other than its owner.

**Revoking access.** Access can be revoked at any time at
https://myaccount.google.com/permissions.
